# Unrivaled Basketball

> Unrivaled is a U.S. professional women's 3x3 basketball league co-founded by Napheesa Collier and Breanna Stewart, playing a winter season with six clubs and a midseason 1-on-1 tournament. Its official real-time data API is operated by Sportradar, the league's Official Data Provider, as the Unrivaled API v8.

## APIs

- [Unrivaled API v8 overview (Sportradar)](https://developer.sportradar.com/basketball/reference/unrivaled-overview): Official league data API — schedules, standings, rosters, real-time scores, play-by-play, injuries, transfers, and season statistics. Base URL https://api.sportradar.com/unrivaled/ with api-key authentication (x-api-key header), JSON or XML responses.
- [Unrivaled API Basics / integration guide](https://developer.sportradar.com/basketball/docs/unrivaled-ig-api-basics): RESTful B2B API, TLS 1.2+, English only, no pagination, current version v8. Covers the 3x3 format, the 1-on-1 midseason tournament, the Elam Ending period type, and weighted free throws.
